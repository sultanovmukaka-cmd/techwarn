# Команда и роли (Agents)

## Frontend Developer №1 (Текущий агент)
- **Зона ответственности**: Главная страница и интерактивная карта WarnTech.
- **Ключевые компетенции**:
  - Проектирование и верстка адаптивного пользовательского интерфейса (Mobile, Tablet, Desktop).
  - Интеграция картографического движка Leaflet + OpenStreetMap.
  - Разработка кастомных маркеров для различных коммунальных служб (вода, газ, электричество).
  - Реализация системы фильтрации аварий по типам и статусам.
  - Реализация поиска по адресу и геолокации инцидентов.
  - Интерактивные карточки и модальные окна с подробной информацией об авариях при клике на маркер.

## Смежные роли (для будущей интеграции)
- **Frontend Developer №2**: Личный кабинет диспетчера, формы подачи заявок об авариях, уведомления.
- **Backend Developer**: REST / WebSocket API для синхронизации инцидентов в реальном времени, интеграция с ГИС ЖКХ.
- **QA Engineer**: Автоматизированное и ручное тестирование UI и карт, проверка корректности координат и фильтрации.
- **DevOps**: CI/CD, сборка Docker-контейнеров, развертывание и балансировка нагрузки картографических тайлов.
